# 商业化与上架合规清单

> 版本：v1.0 ｜ 日期：2026-09-18 ｜ 状态：结论性，但**不构成法律意见**

## 0. 一句话结论

**能。代码层面 MIT 明确允许你独立上架、售卖，不需要原作者同意，也不需要分成。**

真正的门槛不在代码，在**美术资产**和 **Live2D Core** 两处。

---

## 1. 门槛一：代码（MIT）—— 已满足

MIT 是宽松许可（permissive license），明确授予：**使用、复制、修改、合并、发布、分发、再许可、销售**。

| 问题 | 答案 |
|---|---|
| 能卖吗 | 能，MIT 明文允许 sell |
| 要给原作者分成吗 | 不需要 |
| 要原作者同意吗 | 不需要 |
| **衍生作品必须开源吗** | **不必须**。MIT 不要求衍生作品开源，你可以把新增部分闭源售卖 |
| 唯一义务 | 保留原作者版权声明 + MIT 许可文本（已在 NOTICE.md 与 LICENSE 中满足） |

### 一个战略警告

**已经公开的代码收不回来。**

如果你未来打算把新增功能闭源售卖，那么**从现在起就不要再把新代码推进公开仓库**——别人已经 fork 走的部分，你无法禁止其使用。

如果决定商业化，建议现在就分叉：
- 公开仓库：保留基础框架，继续 MIT，用来做口碑和获客
- 私有仓库：付费功能（如照片转桌宠）在此开发，不公开

---

## 2. 门槛二：美术资产 —— 唯一硬卡点

这是目前**唯一会真正咬人**的地方。

| 资产 | 能否随商业产品分发 |
|---|---|
| `src-tauri/assets/models/` 下三套默认猫模型 | ❌ **不可以**，来源继承自上游，授权待澄清 |
| Bongo Cat 形象本身 | ❌ **不可以**，画师 @StrayRogue（2018），仅口头许可原网站 |
| 自己原创 / 购得商用授权的素材 | ✅ 可以 |
| CC0 素材 | ✅ 可以 |
| CC-BY 素材 | ✅ 可以，但**必须署名** |
| 纯 AI 生成图 | ⚠️ 有风险，美国版权局不承认纯 AI 图有版权，需人工二次加工 |

**硬要求：正式发布（v1.0）之前，默认模型必须全部替换。**

---

## 3. 门槛三：Live2D Core —— 基本可行，但有一个坑

来源：Live2D 官方 SDK 授权页（2026-09-18 核实）

- **许可只在"发布"时要求**，开发和试用阶段不需要
- **个人与小规模企业：免除许可协议和费用**（Expandable Application 除外）
- 桌面宠物属于 **Native Application**；若一次性买断售卖，对应 **F 计划（Console or PC 一次性购买）**
- 如需签约，须在**发布前至少一个月**完成手续

### ⚠️ 坑：Expandable Application

Live2D 对 "Expandable Application" 的定义是：**在利用 SDK 的服务或内容中具有显著可扩展性的作品**，需事先送审并签署专门的发布许可。

**你们的路线图恰好踩在这条线上**：
- 阶段二「换外观模型」—— 若支持用户导入任意 Live2D 模型
- 阶段三「照片变桌宠」—— 若涉及模型生成能力

这两项都可能被认定为具备"可扩展性"。

**建议动作**：在阶段二开工前，发一封英文邮件给 Live2D 说明形态并确认是否需送审。**免费，且能一次性排除最大不确定性。** 页面上有联系入口。

另外：Live2D Cubism **Core 是专有许可**（Framework 为开源），相关声明必须保留。

## 4. 上架实操（Microsoft Store）

来源：Microsoft Learn 官方文档（2026-09-18 核实）

| 项 | 情况 |
|---|---|
| 个人开发者账号 | **免费**（原 $19 已免除），需政府证件 + 自拍做身份验证 |
| 公司开发者账号 | 约 $99 一次性，需 D-U-N-S 或营业执照 |
| 非游戏应用收益 | 可用**自有支付系统，100% 归你**；用微软商务平台则抽 15% |
| 代码签名 | **MSIX 打包由微软免费提供签名** + 免费托管 + 自动更新 |
| 商店抽成 | 自选支付则无抽成 |

### 为什么强烈建议走 Store + MSIX

阶段二引入全局键鼠监听后，**杀软极易误报为键盘记录器**。自己买 OV 代码签名证书约 ¥1000–3000/年。

走 Microsoft Store + MSIX：
- 微软免费签名 → SmartScreen 警告消失
- 用户信任度显著高于"从网盘下 EXE"
- 免托管、自动更新都省了

**这是本项目性价比最高的一个决策。**

### 账号类型选择提醒

微软对个人账号的定义偏向"非商业 / 爱好 / 小规模"。如果你是真的以商业身份持续售卖，可能应使用 Company account（$99）。规模做起来后再切换更稳妥。

## 5. 现实性判断

**桌宠软件本身收费，几乎没有成功先例。** 这个品类的付费意愿极低，同类免费开源项目一堆。

真正卖得动的是：
- 模型 / 形象定制（Booth 上 ¥350–1400/个，定制 ¥3500–3.5万+）
- 企业 / 活动定制交付
- 用开源版换影响力，再靠别的变现

### 由此得到的护城河结论

**因为代码是 MIT，别人可以合法地拿你的代码重新分发甚至售卖。**

所以你的护城河**不能建在代码上**，必须建在：
- 美术资产（原创形象，别人抄不走）
- 品牌与社区（模型生态、用户沉淀）
- 服务（定制交付）
